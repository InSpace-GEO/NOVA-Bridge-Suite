# InSpace onboarding assets

The Service CPT administration wizard follows the user-provided [InSpace brand guide](https://marketing.inspace.io/brand-guide/), **v3.5 Proposal**. This notice records the design reference and asset sources; the full private guide and internal content are not included.

The original monochrome SVGs are distributed unchanged from InSpace's official media kit:

- `inspace-wordmark.svg`: [official wordmark source](https://inspace.io/wp-content/themes/inspace/assets/press/inspace-wordmark.svg).
- `inspace-mark.svg`: [official geometric mark source](https://inspace.io/wp-content/themes/inspace/assets/press/inspace-mark.svg).
- [InSpace media kit](https://inspace.io/en-nl/press).

These assets identify InSpace in the administration wizard. They are not added to customer service pages, which inherit the site's own fonts and branding.

The bundled fallback fonts come from the official Google Fonts repository and retain the **SIL Open Font License 1.1**:

| Bundled file | Family | Official source | Included license |
| --- | --- | --- | --- |
| `fonts/space-grotesk.ttf` | Space Grotesk, variable weights 300-700 | [Google Fonts Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) | [OFL-spacegrotesk.txt](fonts/OFL-spacegrotesk.txt) |
| `fonts/space-mono-regular.ttf` | Space Mono, regular weight 400 | [Google Fonts Space Mono](https://github.com/google/fonts/tree/main/ofl/spacemono) | [OFL-spacemono.txt](fonts/OFL-spacemono.txt) |

The license files preserve the respective Space Grotesk Project Authors and Space Mono Project Authors copyright notices. No Aeonik or TT Commons Pro Mono font files are redistributed. CSS lists those families for installations that already have them and uses the bundled open-source fonts as fallbacks.
